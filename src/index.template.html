使い方と注意事項

基本操作

  1. 同じ構図で撮り直したい元写真を選びます。この時点ではカメラを起動しません。
  2. 元写真を確認して「カメラを開始」を押します。ライブ映像に元写真が半透明で重なります。
  3. 元写真を1本指で移動、2本指で拡大・回転して構図を合わせます。PCではドラッグとマウスホイールも使えます。
  4. 構図が合ったら撮影します。撮影後はBefore / Afterを比較して、新しい写真をJPEGで保存できます。

プライバシー

元写真、カメラ映像、撮影画像はブラウザ内だけで処理します。このアプリから外部サーバーへ送信せず、写真をブラウザ内へ自動保存もしません。

注意事項

  • カメラはブラウザのセキュリティ制約により、HTTPSまたはlocalhostでの利用が基本です。単一HTMLを直接開いた場合はカメラを利用できないことがあります。
  • v0.1では自動構図解析はまだありません。元写真の重ね表示と手動調整で構図を合わせます。
  • 撮影画像は自動保存されません。必要な写真は撮影後に「新しい写真を保存」を押してください。

実行時の外部通信はありません。写真とカメラ映像は完全ローカル処理です。

比較HTMLを保存しますか？

比較HTMLには元写真と新しい写真の両方を埋め込みます。このHTMLを誰かへ送ると、写真も相手へ渡ります。

HTMLは外部通信なしで単体表示できます。
